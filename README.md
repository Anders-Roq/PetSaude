## 🐾 PetSaúde
 
**Aplicativo Android para tutores de animais de estimação acompanharem consultas veterinárias e vacinas de forma simples, intuitiva e centralizada.**
 
> Projeto desenvolvido para a disciplina de Desenvolvimento Mobile — Análise e Desenvolvimento de Sistemas | IFPE
 
</div>
 
## 📋 Sobre o Projeto
 
O **PetSaúde** centraliza todas as informações de saúde dos animais de estimação em um único lugar, oferecendo acesso rápido e fácil para qualquer tutor que precise organizar dados médicos, vacinas e consultas do seu pet.
 
---
 
## 👥 Público-alvo
 
Qualquer pessoa que possua um animal de estimação e necessite de uma forma prática de centralizar as informações de saúde do seu animal doméstico.
 
---
 
## ✨ Funcionalidades
 
- 🐶 **Cadastro de pet** — nome, raça, idade, peso, sexo, pelagem, foto e, opcionalmente, microchip.
- 🏥 **Agenda de consultas** — com marcação do local no mapa, registro do motivo bem como a data e o horário.
- 📋 **Controle de vacinas** — histórico das vacinas dadas com a data da aplicação e a data da próxima.
- 🔔 **Alertas e notificações** — lembretes para as próximas vacinas.
- 🗺️ **Visualização em mapa** — visualização do endereço da clinica via Google Maps API
- 📋 **Informações da raça** — visualização em lista das principais características gerais da raça de cão ou gato via API
